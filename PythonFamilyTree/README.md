Python family tree project [feature 1, 2 and 3]

This application allows users to build and explore a family tree using an object-oriented approach in Python. Users can add family members, define relationships (e.g., parent, child), and display the structure of the family tree in a readable format. The program enables traversal and querying of family connections, such as ancestors or descendants of a particular person.
Involving OOP principles, Python, File handling, Data validation, Custom class structures, Inheritance, Encapsulation, Graph/tree traversal algorithms.

I have learnt to:
Design and implement object-oriented systems in Python
Apply principles of inheritance and encapsulation
Manage and traverse hierarchical data structures
Create custom methods for managing dynamic relationships
Validate data inputs to prevent logical errors
Use file handling to save and retrieve persistent data
Implement recursion and tree traversal techniques

Self-reflection: This project helped me better understand how to represent real-world relationships in code through OOP. It taught me how to model complex data structures like trees and manage them efficiently. In the future, I would like to enhance the interface by integrating a GUI using Tkinter, allowing for more intuitive interactions with the family tree.
