Boolean logic calculator using flex and bison [boolcalc.y and boolcalc.l]
- This project is a command-line Boolean logic calculator that evaluates expressions containing TRUE, FALSE, AND, OR, and NOT operations. The calculator is implemented using Flex (for lexical analysis) and Bison (for 
  parsing). Users input Boolean expressions in infix notation, and the program outputs the evaluated result as either TRUE or FALSE.
- Involving Flex (Lex) for lexical analysis Bison (Yacc) for parsing and syntax tree generation, C programming language, Abstract Syntax Tree (AST) evaluation, Postfix expression construction and evaluation, Error 
  handling and recovery, Use of token types and grammar rules, Custom operator precedence handling
- I have learnt: 
  1. Write lexical analysers using Flex
  2. Design grammars and parse rules using Bison
  3. Build a simple compiler pipeline: tokenising, parsing, evaluating
  4. Evaluate Boolean expressions using logical operators
  5. Handle input from stdin and manage continuous input until EOF
  6. Implement error handling and user-friendly output formatting
  7. Use yylval and %token definitions to pass and manage values
- Self-reflection: This project gave me hands-on experience with compiler construction principles and deepened my understanding of parsing logic. It helped bridge theoretical concepts like lexical and syntax analysis 
  with practical implementation.
