
This project combines technical operating‑system calculations with research-based analysis across modern OS architectures. It includes CPU performance evaluation, scheduling algorithms, memory allocation strategies, and comparative research on Fuchsia, ROS, and DBOS.

---

## **Project Features**
- CPU performance calculations for a hypothetical 16‑bit processor  
- Cache hit/miss analysis and Average Data Access Time (ADAT) computation  
- Scheduling algorithm evaluation (FCFS and SJN)  
- Memory allocation strategy comparison (First Fit, Best Fit, Next Fit, Worst Fit)  
- Research on scalability, security, real‑time processing, and application design across three modern operating systems  
- Critical evaluation supported by academic and industry sources  

---

## **Project Description**
- Analyses how cache performance affects CPU efficiency using ADAT formulas.  
- Compares scheduling algorithms by calculating waiting and turnaround times.  
- Evaluates memory allocation strategies across two scenarios to understand fragmentation and efficiency.  
- Researches three modern operating systems — Fuchsia, ROS, and DBOS — focusing on scalability, security, real‑time processing, and application design.  
- Connects OS design principles to real‑world use cases such as robotics, IoT, and distributed cloud systems.

## **Key Research Insights**
### **Scalability**
- Fuchsia uses FIDL for flexible IPC across hardware types  
- ROS 2 uses DDS for decentralised discovery and multi‑robot scalability  
- DBOS stores OS state in a distributed SQL system for cloud‑scale consistency  

### **Security**
- Fuchsia uses strict sandboxing and least‑privilege isolation  
- ROS 2 uses PKI‑based encryption for secure node communication  
- DBOS uses authentication and access control to prevent unauthorised system access  

### **Real‑Time Processing**
- Fuchsia’s Zircon kernel uses dynamic scheduling for adaptive prioritisation  
- ROS 2’s DDS enables low‑latency, reliable message passing  
- DBOS uses durable queues for distributed workflow execution  

### **Applications**
- Fuchsia supports modular IoT systems with component‑based updates  
- ROS 2 supports autonomous robotics with QoS‑controlled sensor integration  
- DBOS supports ML pipelines with exactly‑once transactional state
