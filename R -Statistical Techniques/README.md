# **Birth Weight Analysis with R**
This project investigates factors associated with birth weight using R. It includes exploratory data analysis, comparison of group means, normality checks, non‑parametric testing, categorical hypothesis testing, and simulation to understand p‑values and statistical power. The dataset is a modified version of the MASS **birthwt** dataset, with randomisation applied to birth weights and smoking status.

---

## **Project Features**
- Exploratory Data Analysis (EDA) of numerical and categorical variables  
- Group comparison using t‑tests and Wilcoxon rank‑sum tests  
- Normality assessment using QQ‑plots and histograms  
- Categorical hypothesis testing using Chi‑squared and Fisher’s exact tests  
- Simulation of p‑values to understand randomness and statistical power  
- Interpretation of statistical results in a real‑world context  

---

## **Project Description**
This analysis explores how maternal characteristics relate to birth weight. The dataset includes 100 observations and 10 variables, with deliberate randomisation applied to birth weights and smoking status.

The project walks through:

- Summarising numerical variables  
- Visualising distributions  
- Testing differences between smokers and non‑smokers  
- Checking assumptions of parametric tests  
- Running non‑parametric alternatives  
- Analysing categorical associations  
- Simulating repeated experiments to understand p‑value behaviour  

The project demonstrates how statistical conclusions change depending on assumptions, sample size, and randomness in the data.

---

## **Technologies & Methods Used**
- R programming language  
- `dplyr` for data manipulation  
- Base R statistical functions  
- Hypothesis testing (t‑test, Wilcoxon, Chi‑square, Fisher’s exact)  
- Data visualisation (boxplots, histograms, QQ‑plots)  
- Simulation using `rnorm()`  
- Confidence intervals & effect size interpretation

## **What I Learned**

- How categorical hypothesis tests work and when to use Fisher vs Chi‑square
